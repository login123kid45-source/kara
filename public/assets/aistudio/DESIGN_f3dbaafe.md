## Brand & Style

This design system establishes an instrument-grade, high-cognition workspace engineered for synthesized multi-model orchestration. The system resolves the tension between three prevailing paradigms in frontier AI interfaces: Grok's raw real-time telemetry and cybernetic density, Gemini's fluid multimodal spatial canvas, and Claude's warm, contemplative editorial rigor and inspectable reasoning chains.

The target audience comprises frontier AI researchers, prompt engineers, system architects, and technical creators who demand zero-latency visual feedback, structural transparency, and total control over parallel model execution. The interface feels like an advanced scientific console wrapped in an editorial reading room—hyper-precise, quiet, yet glowing with latent computational power.

The aesthetic fuses **Technical Minimalism** with **Atmospheric Glassmorphism** and **Chamber Noir**:
- **Monolithic Substrates:** Deep, pitch-black canvases (`#090A0F`) anchored by subtle structural divisions rather than heavy containers.
- **Spectral Model Signatures:** Pure chromatic light accents denote distinct generative engines without chromatic pollution: Electric Violet (`#8B5CF6`) for emergent synthesis, Laser Cyan (`#06B6D4`) for real-time telemetry/web grounding, and Warm Solar Amber (`#F59E0B`) for deep analytical reasoning.
- **Typographic Dialectic:** High-tension interplay between a warm, literary modern serif for synthetic prose outputs, an architectural grotesque for fluid operational layouts, and a surgical monospace for reasoning tokens and telemetry metrics.

## Colors

The palette is engineered exclusively for an immersive, reduced-eyestrain dark ecosystem where luminance conveys cognitive priority and computational state.

### Core Architecture
- **Canvas Base (`#090A0F`):** The absolute abyss layer. Zero pure RGB `#000000` to prevent OLED shearing during motion.
- **Surface Elevation 1 (`#11131F`):** Structural pane backgrounds and collateral dock foundations.
- **Surface Elevation 2 (`#181B2C`):** Interactive card layers, inspector drawers, and floating panels.
- **Surface Elevation 3 (`#22263D`):** Active popovers, context menus, and hover highlights.

### Model Vectors & State Tokens
- **Synthesis Primary (`#8B5CF6` / Electric Violet):** Orchestrator nodes, multi-agent synthesis, and primary intent pathways.
- **Telemetry Secondary (`#06B6D4` / Laser Cyan):** Live web-grounding stream, tool-use execution, throughput tokens/sec indicators, and vector retrieval signals.
- **Reasoning Tertiary (`#F59E0B` / Solar Amber):** Chain-of-thought expansion tags, epistemic uncertainty meters, human-in-the-loop validation barriers, and warning thresholds.
- **Text Primary (`#F1F5F9`):** 96% luminance slate-white for core prose and artifact reading.
- **Text Secondary (`#94A3B8`):** 65% luminance for interface chrome, metadata, and structural headers.
- **Text Muted (`#475569`):** 40% luminance for passive line numbers, grid coordinates, and inactive borders.

## Typography

The typographic hierarchy implements an intentional tripartite split to cleanly separate narrative machine synthesis from interface controls and operational telemetry.

1. **Synthetic Generation & Artifact Prose (`Literata`):** Applied to AI responses, generated essays, synthesized documents, and editorial content. The warm serifs provide high visual fatigue resistance during long reading and editing sessions, lending an authoritative, humanized weight to complex conceptual outputs.
2. **Workstation Shell & Spatial Canvas (`Plus Jakarta Sans`):** Applied to application chrome, tool dock actions, inspector navigation, modals, and user inputs. Its geometric balance ensures legibility at small sizes without sterile rigidity.
3. **Telemetry, Artifact Inspection & Code (`JetBrains Mono`):** Applied to system tokens, real-time compute latency metrics, token consumption counts, raw prompt editors, AST views, and model telemetry streams. The optical precision reinforces an instrument-grade feel.

## Layout & Spacing

The spatial layout leverages an asymmetric fluid workbench model optimized for horizontal tri-pane orchestration:
- **Left Dock (Operational Anchor):** Slim 64px icon dock expanding to a 280px contextual session tree.
- **Center Canvas (Fluid Generation Substrate):** Dynamic width spanning 600px minimum to 960px optimal reading column width, perfectly centered when inspectors are closed.
- **Right Inspector (Multimodal / Telemetry Drawer):** Fixed 420px to 640px resizable panel displaying model internal representations, artifact execution environments (HTML/React/Python preview), and live reasoning graphs.

### Responsive Breakpoints & Adaptive Reflow
- **Desktop (>= 1280px):** Full 3-pane concurrent view. Center conversational canvas, persistent tool dock, and persistent live artifact drawer side-by-side.
- **Tablet (768px - 1279px):** Split-view workspace. Left navigation collapses into a minimal rail. The right inspector transitions to an overlay sheet triggered via tool dock tabs or direct interaction with artifact pill tokens.
- **Mobile (< 768px):** Strict single-column stack. Reasoning chains collapse into expandable cards. Artifacts open into full-screen sliding views. Tool dock anchors permanently to the bottom screen edge with safe-area spacing.

## Elevation & Depth

Visual hierarchy does not use classic dropped drop-shadows; instead, it relies on **Atmospheric Glassmorphism**, optical edge luminescence, and surface luminosity tiers.

### Depth Paradigm
- **Base Canvas (Level 0):** Pure dark field (`#090A0F`), static background with a low-intensity, radial chromatic mesh indicating ambient compute activity.
- **Structural Panels & Wells (Level 1):** Solid `#11131F` with a 1px border colored `rgba(255, 255, 255, 0.06)`. Zero blur, high performance.
- **Floating Modals & Artifact Cards (Level 2):** Semi-translucent `#181B2C` blended at 85% opacity with a `16px` backdrop filter blur (`backdrop-filter: blur(16px)`). Borders receive top-edge specular highlights using linear gradients (`rgba(255, 255, 255, 0.12)` fading to `rgba(255, 255, 255, 0.02)`).
- **Transient HUDs & Tool Docks (Level 3):** Floating chrome units with a `24px` backdrop blur, 75% surface fill, and an ultra-subtle directional chromatic glow tinted to the active model:
  - Violet: `0 8px 32px -4px rgba(139, 92, 246, 0.15)`
  - Cyan: `0 8px 32px -4px rgba(6, 182, 212, 0.15)`
  - Amber: `0 8px 32px -4px rgba(245, 158, 11, 0.15)`

## Shapes

The design uses a refined balance of curved geometry to bridge Gemini's organic fluidity with the sharp precision of scientific telemetry tools.

- Standard buttons, input bars, inline code capsules, and chips utilize **`rounded` (`0.5rem` / `8px`)** to preserve structural compactness without aggressive corners.
- Canvas cards, artifact preview windows, and telemetry data tables scale up to **`rounded-lg` (`1rem` / `16px`)**.
- Floating interactive docks, agent switchers, and tool-trigger pills utilize **`rounded-xl` (`1.5rem` / `24px`)**, signaling tactile clickability and gesture responsiveness.
- Inline status dots, latency indicators, and model avatar badges remain pure circles.

## Components

### Buttons & Interactive Controls
- **Primary Execution Button:** Solid Electric Violet background (`#8B5CF6`) with dark slate typography (`#090A0F`), bold weight, and an interior inset edge highlight. Hover triggers a subtle outward cyan halo.
- **Secondary Ghost Controls:** Transparent backgrounds framed by a 1px hairline border (`rgba(255, 255, 255, 0.08)`). On hover, background shifts to `rgba(255, 255, 255, 0.04)` with foreground text illuminating from slate to pure white.
- **Telemetry Buttons:** Monospaced label indicators with embedded pulsing status LEDs signaling streaming states (`active`, `idle`, `stalled`).

### Reasoning Chain Accordions (Claude Transparency)
- Stacked collapsible containers utilizing Surface Elevation 1 (`#11131F`).
- Headers feature an Amber status pip (`#F59E0B`), monospaced duration readouts (`"Thought for 4.2s"`), and an accordion toggle arrow.
- Inner reasoning body sets text in `body-sm`, colored `#94A3B8`, framed by a 2px vertical solar-amber border line on the left margin, demarcating inner reflection from definitive output.

### Interactive Tool Dock (Rich Floating Controls)
- Suspended floating island anchored at the bottom-center of the active viewport.
- Contains contextual multimodal triggers: Image upload, Web-search toggles, Code Interpreter activation, and Temperature scrubbers.
- Translucent frosted glass backing with individual tool icons that light up in their associated model colors when engaged (Cyan for Web ground, Violet for synthesis, Amber for reflective analysis).

### Multimodal Input Matrix
- Auto-expanding input field enclosed in a continuous 1px glass border that dynamically shifts hue based on the primary model selected.
- Direct attachment thumbnails display mini technical badges: aspect ratio, file size, and token weight.

### Chips & Model Indicator Badges
- Pill capsules (`1.5rem` radius) combining `JetBrains Mono` label text with a saturated neon icon.
- Cyan chips for Real-Time Telemetry / Grounding nodes.
- Violet chips for Synthesis / Composite outputs.
- Amber chips for Epistemic Reasoning / High-Verification passes.

### Artifact Cards & Side-by-Side Inspectors
- Dual-mode card modules featuring a top segmented controller: `[Code]`, `[Preview]`, `[Console]`.
- Top-right action cluster houses "Copy Raw", "Fork Model Tree", and "Pop to Window" utility triggers.
- Code views implement syntax highlighting over a darker `#0B0D14` background with line numbers locked to `JetBrains Mono`.

### Form Fields & Inputs
- Dark inset backgrounds (`#0C0E17`) with an inset box-shadow to simulate internal depth.
- Placeholder text set to `rgba(148, 163, 184, 0.4)`.
- Active focus state replaces borders with an Electric Violet-to-Cyan subtle linear border gradient.
